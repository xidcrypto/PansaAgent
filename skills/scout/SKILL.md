# Scout Skill

Not implemented. There is no on-chain scanner in this version, so the
skill returns an error instead of invented campaigns, risk levels, or
reward values.

Do not present scout results as real data. If a user asks for
opportunity scanning, say it is not available and offer the tracker,
scam_check, and report tools instead.
